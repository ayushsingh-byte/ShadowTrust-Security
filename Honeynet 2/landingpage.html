Shadow Trust Cyber Range Orchestration

Shadow Trust is a modular backend platform for orchestrating honeypot VMs, collecting attack telemetry, automating malware analysis, and visualizing threat intelligence. Designed for research, analysis, and scalable security operations.

Explore Platform Backend Engine

Core Backend Capabilities

Orchestration Dashboard

Central command center for launching analysis VMs, tracking honeypot activity, and visualizing attack sessions. Powered by Supabase for real-time updates.

Live Honeypot VMs

Ephemeral AWS EC2 instances deployed from Golden AMIs, exposed to the internet for threat collection. All activity is monitored and logged by telemetry agents.

Malware Collection Pipeline

Automated detection and collection of uploaded files, instant transfer to secure S3 storage, hash computation, and metadata association with attacker sessions.

Analysis Sandbox VMs

On-demand analysis environments (Windows, Kali, MobSF, IDA) for static, dynamic, and binary analysis. VMs are launched, registered, and terminated automatically.

Backend Architecture

Shadow Trust backend leverages AWS EC2 and VPC for secure VM orchestration, Supabase for real-time data streaming, and SQLite for high-frequency event ingestion. All VMs are ephemeral, launched from Golden AMIs, and managed via async FastAPI endpoints. No public management ports are exposed; access is via AWS SSM browser sessions.

Real-Time Telemetry & Monitoring

When an attacker interacts with our honeypot VMs, lightweight agents capture host logs, network activity, and shell commands in near real-time. This structured telemetry is securely forwarded, indexed, and streamed back to the dashboard. Observe every keystroke, exploited service, and persistence attempt instantly.

View Logs Demo

Automated Malware Collection

If an attacker uploads any script, binary, or APK, automated collectors detect file creation events. The samples are instantly transferred into an isolated secure storage pipeline (S3). Metadata including file hashes, attacker IP associations, and behavioral context is preserved for deep analysis, while the compromised VM is safely terminated.

Phishing & Sandbox Analysis

Our integrated analysis capabilities support on-demand reverse engineering VMs loaded with IDA and MobSF. Additionally, the phishing intelligence module evaluates suspicious links using threat intel APIs and machine learning, generating safe previews of URLs inside an isolated rendering environment.
