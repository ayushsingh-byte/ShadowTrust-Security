Introduction to Shadow Trust Backend

v1.0.0

Welcome to the official documentation for the ShadowTrust Threat Intelligence Platform. This guide will help you understand the backend architecture, async orchestration model, and how to integrate Shadow Trust with your local dashboard, AWS infrastructure, and Supabase database.

Overview

Shadow Trust backend orchestrates honeypot and analysis VMs from Golden AMIs, ingests telemetry from attacker sessions, stores events in SQLite and Supabase, and exposes async FastAPI endpoints for VM lifecycle, session management, and analysis workflows. All VMs are ephemeral and managed securely via AWS SSM browser sessions.

python 
# Quickstart: Launch a VM via FastAPI
import requests

resp = requests.post('http://localhost:8000/vm/launch', json={
    "profile": "kali",
    "user_id": "demo_user"
})
print(resp.json())

# Ingest telemetry event
event = {
    "attacker_ip": "192.168.1.10",
    "timestamp": "2026-02-27T12:00:00Z",
    "protocol": "ssh",
    "honeypot_type": "linux",
    "session_id": "sess123",
    "commands": ["ls", "cat /etc/passwd"],
    "uploaded_files": [],
    "ports_scanned": [22, 80],
    "geoip": "IN",
    "risk_score": 7.5,
    "raw_payload": "..."
}
requests.post('http://localhost:8000/events', json=event)
Note: All backend endpoints are async and require proper authentication. Refer to the API docs for endpoint details and request formats.
