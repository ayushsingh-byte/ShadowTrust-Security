Introduction to Shadow Trust

v2.0.0

Shadow Trust is a full-stack, AI-powered Security Operations Center platform that combines honeypot deception, real-time telemetry, malware analysis, and AWS VM orchestration into a single 5-service Docker stack.

Quick Start — Docker (Recommended)

The fastest way to get Shadow Trust running. Requires only Docker Desktop.

bash 
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/Shadow-Trust.git
cd Shadow-Trust

# 2. Run the one-click setup wizard
./setup.sh

# The wizard will:
#   - Detect your OS (macOS / Linux / Windows)
#   - Create .env files from templates
#   - Touch SQLite database files
#   - Build all 5 Docker images
#   - Start all services in detached mode

# Access the platform:
# Dashboard  →  http://localhost:5500
# API Docs   →  http://localhost:8000/docs
# MobSF      →  http://localhost:5055
# Node API   →  http://localhost:3000

Key Environment Variables

All credentials live in backend/.env. Required fields:

env

SECRET_KEY=your-jwt-secret-key
SUPABASE_URL=https://YOUR_PROJECT.supabase.co

SMTP_PASS=your-app-password

# WhatsApp alerts (optional)
TWILIO_ACCOUNT_SID=ACxxxxxxxx
TWILIO_AUTH_TOKEN=your-token

# AWS VM orchestration (optional)
AWS_ACCESS_KEY_ID=
AWS_SECRET_ACCESS_KEY=
AWS_REGION=us-east-1

RBAC — Roles & Access Levels

Shadow Trust uses a 6-tier role model with clearance levels. Set the first Super Admin in Supabase:

sql 
-- In Supabase SQL Editor: promote first user to super_admin
UPDATE users SET role = 'super_admin', clearance_level = 3
WHERE email = 'your@email.com';
Roles: super_admin (3) → overseer (3) → auditor (2) → analyst (2) → specialist (2) → operative (1). Higher clearance unlocks VM lab, malware pipeline, and admin panel.

Authentication API

All API calls require a JWT Bearer token obtained from the login endpoint.

python 
import requests

# Login and get JWT token
resp = requests.post('http://localhost:8000/api/v1/auth/login', json={
    "username": "operator@example.com",
    "password": "your-password"
})
token = resp.json()["access_token"]
headers = {"Authorization": f"Bearer {token}"}

Launch Analysis VM

python 
# Launch an AWS EC2 analysis VM
resp = requests.post('http://localhost:8000/api/v1/vm/launch', json={
    "profile": "kali",
    "session_id": "sess_abc123",
    "user_id": "analyst_01"
}, headers=headers)

vm = resp.json()
print(f"VM launched: {vm['instance_id']} — access via Guacamole")

# Terminate when done
requests.post(f'http://localhost:8000/api/v1/vm/terminate/{vm["instance_id"]}',
              headers=headers)

Make Commands

bash 
make setup       # First-time setup (same as ./setup.sh)
make up          # Start containers (no rebuild)
make down        # Stop all containers
make rebuild     # Rebuild images + restart
make logs        # Tail all container logs
make logs-backend  # Backend logs only
make status      # Show container status
make shell-backend # Shell into FastAPI container
make clean       # Remove containers + images
make nuke        # ⚠ Remove everything including volumes
