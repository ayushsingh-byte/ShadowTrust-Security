    01 · Deceive

    Put out services that look worth breaking into.

    Three open-source honeypots run as containers next to the platform. They answer like real servers, so scanners and bots keep talking long enough to show their hand.

    • cowrieSSH and Telnet with a believable shell
    • dionaeaSMB, FTP and MSSQL, keeps whatever is uploaded
    • honeytrapCatches traffic on the leftover web ports
    02 · Capture

    Every keystroke lands in the database within seconds.

    Each sensor writes JSON lines. A collector follows the files from their last byte offset, normalises the fields, writes batches into MariaDB and pushes each new event to open dashboards over Server-Sent Events.

    • sourceLocal files or S3, same collector
    • storeMariaDB, browsable in phpMyAdmin
    • streamSSE, no polling loop in the browser
    03 · Enrich

    Context gets attached before anyone looks.

    Events are geolocated, mapped to MITRE ATT&CK techniques by event type and command content, and risk scored. Files that attackers drop are hashed and scanned with ClamAV and YARA.

    • att&ckT1110, T1059, T1046, T1105, T1190 and more
    • filesSHA-256, ClamAV, YARA, optional VirusTotal
    • appsAPKs go through MobSF
    04 · Correlate

    Noise turns into a single case with a timeline.

    Detection rules written in a Sigma-style YAML format watch the event stream. When one fires, related events from the same source and session are grouped into an incident with severity, evidence and an ordered timeline.

    • 6 rulesBrute force, login after brute force, payload download, scan, post-exploit command, PowerShell
    • 8 testsValidation scenarios replay attacks to prove each rule fires
    05 · Respond

    Hand over something finished.

    Analysts work the case in Investigations, then export a PDF report. The same evidence feeds a SOC 2 readiness view, so monitoring and incident handling are documented as they happen.

    • reportsExecutive, incident, geo, malware, credentials, DFIR
    • grcSOC 2 criteria, risk register, evidence
    • accessSix roles, enforced by the API
