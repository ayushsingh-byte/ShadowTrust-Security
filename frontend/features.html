Features

A whole SOC, wired together.

Honeypot deception, live telemetry, detection rules, ATT&CK mapping, malware and APK analysis, URL scanning, lab machines and role-based access. Every tool reads from and writes to the same database, so nothing has to be stitched together by hand.

Capture

Dionaea keeps whatever is uploaded to it. Cowrie records every wget or curl URL as a file_download event, tied to the session that ran it.


                

            

        

    


    


        

            

                
Deception and capture.

                
Get attackers talking to something that looks real, and keep every word they say.

            

            

            

                

                    
Multi-protocol honeypots

                    
Cowrie captures SSH and Telnet sessions with a believable shell. Dionaea traps malware on SMB, FTP and MSSQL. Honeytrap listens on the leftover web ports. All three feed the same ingestion pipeline and the same session correlation.

                    
cowrie 2222, 2223dionaea 445, 2121, 1433honeytrap 8022, 8023

                

                

            

            

                

                    
Real-time telemetry

                    
Every keystroke, command and file event is tailed from the sensor logs into MariaDB and pushed to open dashboards over Server-Sent Events. The collector uses kernel file notifications where available and reads each line exactly once from a stored byte offset.

                    
inotify with polling fallbackbatched insertsSSE, no polling in the browser

                

                

            

            

                

                    
GeoIP enrichment

                    
Attacker addresses are enriched with country, city, ASN and ISP, then plotted on a keyless OpenStreetMap threat map with origin clustering. Lab-internal addresses are shown as such instead of being guessed.

                    
country, city, ASNkeyless map tiles

                

                

            

            

        


        

            

                
Detection and intelligence.

                
Turn a stream of raw events into a short list of things someone should look at.

            

            

            

                

                    
Attack classification

                    
Events are sorted into categories such as SQL injection, XSS, brute force, remote code execution and path traversal using rule-based classifiers and behavioral patterns. No manual tagging, and every label can be traced back to the rule that produced it.

                    
heuristic, explainableper-event categories

                

                

            

            

                

                    
Detections and session correlation

                    
Six YAML detection rules watch the stream and open incidents with severity and evidence. A background session engine runs every 60 seconds and groups events by source, timing and protocol into full attacker sessions with reconstructed timelines.

                    
6 rules, 8 validation scenarios60 s session engine

                

                

            

            

                

                    
MITRE ATT&CK mapping

                    
Every event is tagged with techniques and tactics based on its type and command content. The matrix page shows which techniques your sensors are catching and the events behind each one.

                    
T1110, T1059, T1046, T1105, T1190, T1595

                

                

            

            

        


        

            

                
Analysis tools.

                
Open what attackers left behind without leaving the console.

            

            

            

                

                    
Malware pipeline

                    
Hashing and static analysis, ClamAV and YARA signatures, optional dynamic analysis in a CAPE sandbox, and extraction of credentials and API keys. When CAPE is not configured the report says dynamic analysis was not run, rather than inventing a result.

                    
PE, ELF, Mach-O, PDF, DOCX, scriptsVirusTotal optional

                

                

            

            

                

                    
APK security analysis

                    
Upload an Android package and MobSF returns a full static report: permission audit, network endpoints, hardcoded secrets and a risk score.

                    
MobSF on port 5055

                

                

            

            

                

                    
URL reputation scanner

                    
DNS, TLS certificate, WHOIS and HTTP probes plus heuristics for homograph domains, entropy and known phishing patterns, with a safe isolated preview of the page.

                    
heuristic scoringisolated rendering

                

                

            

            

                

                    
Lab machines

                    
Kali and analysis desktops run locally and open in the browser through Apache Guacamole. With AWS configured, isolated EC2 instances can be launched on demand, reached through Systems Manager without SSH keys, and terminated when the session ends.

                    
GuacamoleEC2 and SSM optional

                

                

            

            

        


        

            

                
Access and operations.

                
Decide who sees what, and keep a record of it.

            

            

            

                

                    
Six-tier role-based access

                    
Super Admin, Overseer, Auditor, Analyst, Specialist and Operative, with clearance levels 1 to 3 gating sensitive tools. Sessions use JWTs, and admin routes are checked on the server, not just hidden in the interface.

                    
JWTserver-side role checksaudit trail

                

                

            

            

                

                    
Credential delivery

                    
New analyst credentials are issued with one-time tokens and sent by SMTP email or WhatsApp through Twilio when those integrations are configured, with every issue logged.

                    
one-time tokensSMTP, Twilio optional

Why not just a SIEM?

                
A SIEM is good at collecting what you already have. ShadowTrust creates new, high-signal data by giving attackers something to touch.
