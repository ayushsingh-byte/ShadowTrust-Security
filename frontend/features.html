Shadow Trust Platform Features

A complete SOC toolkit — from honeypot deception and real-time telemetry to 4-stage malware analysis, AWS VM orchestration, MITRE ATT&CK mapping, and a 30-page threat intelligence dashboard. Every feature built for real operations.

Capabilities

Everything You Need to Hunt Threats

Shadow Trust combines detection, analysis, and response in a single platform — no stitching together separate tools.

🧠

AI Attack Classification

Automatically classifies SQL injection, XSS, brute force, RCE, path traversal, and anomalous payloads using heuristic rule-based classifiers and behavioral pattern matching. Zero manual tagging.

🍯

Multi-Protocol Honeypots

Cowrie captures SSH/Telnet interactions. Dionaea traps malware binaries. Honeytrap monitors multi-port network traffic. All three feed into the same ingestion pipeline with session correlation.

📡

Real-Time Telemetry

Edge SQLite captures every attacker keystroke, command, and file event locally — offline-resilient. Enriched events sync to Supabase for live dashboard streaming when connected.

🔗

Session Correlation Engine

Groups raw events into attacker sessions with full timeline reconstruction. Background engine runs every 60 seconds, linking events by IP, protocol, and timing. Full attacker lifecycle tracking.

☣️

4-Stage Malware Pipeline

Static analysis → controlled sandbox detonation → Android APK scanning via MobSF → credential and API key extraction. Fully automated from file capture to intelligence report.

🖥️

AWS VM Orchestration

Launch and terminate isolated EC2 analysis instances via boto3. JIT credential injection through AWS Systems Manager. Browser-based remote desktop via Apache Guacamole. Auto-terminate on session end.

🎯

MITRE ATT&CK Mapping

Every detected attack is automatically tagged with MITRE ATT&CK techniques and tactics. Navigate the full matrix from the dashboard and see which techniques your honeypots are catching.

📱

APK Security Analysis

Upload Android APKs directly to the dashboard. MobSF backend delivers full static analysis reports — permission audits, network call mapping, hardcoded secret detection, and risk scoring.

🔗

URL Reputation Scanner

Multi-engine URL analysis with threat intel lookup. Safe isolated preview of suspicious links. Phishing detection with ML scoring. All captured attacker URLs automatically queued for analysis.

🌍

GeoIP Enrichment

Every attacker IP is enriched with country, city, ASN, and ISP data. Plotted on the live threat map with origin clustering and attack density heatmaps across geographic regions.

🔐

6-Tier RBAC System

Super Admin, Overseer, Auditor, Analyst, Specialist, and Operative roles. Clearance levels 1–3 gate access to sensitive tools. JWT-authenticated with full API audit trail.

🔔

Multi-Channel Alerts

Critical threat notifications delivered via Gmail SMTP (Jinja2 templated emails) and WhatsApp via Twilio. Configurable alert thresholds and role-based notification routing.
