Shadow Trust Platform Features

Shadow Trust delivers a modular backend for cyber range orchestration, honeypot telemetry, malware collection, and analysis. The platform enables secure VM lifecycle management, real-time event ingestion, and session reconstruction for advanced threat research and visualization.

Core Backend Features

🛡️

VM Orchestration

Launch, stop, and terminate analysis and honeypot VMs from Golden AMIs. Manage instance lifecycle, tagging, and session mapping with cost-safe automation.

📊

Event Ingestion & Telemetry

Receive structured honeypot logs, normalize events, and store them in SQLite for fast ingestion. Sync to Supabase for dashboard visualization and real-time streaming.

⚡

Session Engine

Link multiple attack events into sessions, reconstruct timelines, and manage session lifecycle for deep attacker profiling and timeline analysis.

🔒

Malware Collection Pipeline

Automatically collect uploaded files, compute hashes, store samples in S3, and link metadata to attacker sessions for further analysis.

🌐

Analysis Orchestrator

Launch analysis VMs, pull samples from S3, register jobs, track job lifecycle, and auto-terminate instances after completion. Integrates with MobSF and URL analysis modules.

☁️

Async API & Real-Time Streaming

All backend operations are asynchronous. Real-time updates are streamed to the dashboard via Supabase or Redis pub/sub, supporting high-frequency telemetry and analysis progress.
