02 Who uses it

Built for every security context.

Hunting advanced threats, training the next analysts or building intelligence feeds. Here is what each setting gets out of it.

Cybersecurity research labs

Run controlled experiments against real malware families. Spin up isolated analysis machines, run samples through the malware pipeline, and capture full attacker techniques through honeypot interaction.

  • On-demand analysis machines
  • Full session timeline reconstruction
  • Automatic malware sample collection
  • APK and binary static analysis, dynamic with CAPE

Enterprise SOC teams

Put decoys inside the network, ingest real attacker telemetry and correlate sessions across the perimeter. Detections show up on the console the moment they fire, and analyst accounts are delivered by email or WhatsApp.

  • Live honeypot telemetry
  • Real-time threat map
  • Detections opening incidents
  • Six-role access control

Academic and training environments

Give students hands-on practice with real threat intelligence work: live attack maps, the ATT&CK matrix, behavioral profiling and the full analyst toolset, in a safe and contained lab.

  • Live attack visualization for demos
  • ATT&CK matrix walkthroughs
  • Separate roles for students and instructors
  • One command to bring the lab up

Threat intelligence providers

Collect telemetry across honeypot nodes, automate malware collection, GeoIP attribution and indicator extraction, and publish structured, enriched data.

  • Honeypot node management
  • Indicator and hash extraction
  • GeoIP-enriched attribution
  • STIX 2.1 export and Splunk forwarding

Government and defence

Run deception infrastructure that catches persistent, skilled actors. The whole stack is self-hosted, so telemetry stays on infrastructure you control, including restricted networks.

  • Self-hosted, no cloud dependency
  • Full ATT&CK technique mapping
  • Audit logs for compliance reporting
  • Runs fully offline once images are built

Incident response teams

While an incident is under way, ShadowTrust gives responders context straight away: behavioral profiles, session timelines, captured credentials and technique mappings, all in one place.

  • Session timeline reconstruction
  • Captured credential viewer
  • URL and hash reputation checks
  • Behavioral profiling across sessions
