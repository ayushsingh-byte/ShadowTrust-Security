Data Flow

How an Attack Flows Through the Platform

From first contact with a honeypot to a full threat intelligence report — every step is automated.

1

🍯 Honeypot Capture

Attackers interact with Cowrie (SSH/Telnet brute force + shell), Dionaea (malware upload), or Honeytrap (multi-port probing). Every keystroke, credential attempt, and uploaded file is recorded. Each sensor appends newline-delimited JSON to its own log file — the only channel out of the isolated honeynet network.

2

📡 Telemetry Ingestion

The FastAPI backend (Python 3.11, Uvicorn async) watches the sensor logs with inotify and tails them from stored byte offsets, so each line is read exactly once. Events are normalized, written to MariaDB and published on an internal event bus that feeds the dashboard's Server-Sent Events stream.

3

🧠 AI Classification & Enrichment

Each event passes through the AI classification engine — detecting SQLi, XSS, brute force, RCE, path traversal, and anomalous payloads. GeoIP enrichment adds country, ASN, and city data. Risk scoring (0–100) is computed. Events are tagged with MITRE ATT&CK techniques automatically.

4

🔗 Session Correlation

The background Session Engine (runs every 60s) groups raw events by attacker IP, timing, and protocol into full attacker sessions. It reconstructs timelines, tracks persistence attempts, and builds behavioral profiles. Sessions power the Behavior and Geo dashboard pages.

5

☣️ Malware Pipeline (4-Stage)

Uploaded files trigger the pipeline automatically: Stage 1 — static analysis (hashes, strings, metadata). Stage 2 — sandbox behavioral detonation. Stage 3 — APK security scan via MobSF Flask proxy (Docker socket). Stage 4 — credential and API key extraction from payloads. Results stored and linked to attacker session.

6

🖥️ VM Orchestration (AWS)

Analysts can launch isolated EC2 analysis environments on demand via /api/v1/vm/launch. Boto3 provisions the instance from a pre-configured AMI. AWS Systems Manager injects credentials JIT — no SSH keys. Apache Guacamole provides browser-based remote desktop. Instances auto-terminate on session end.

7

📊 Dashboard & Alerts

Nginx serves the 30+ page Vanilla JS dashboard on port 5500. The frontend calls the FastAPI backend on port 8000 and receives live events, detections and sensor metrics over Server-Sent Events. Incidents, evidence and PDF reports are generated from the same MariaDB data.

Deployment

Core Docker Services

The entire platform ships as a production-ready Docker Compose stack. One command starts everything.

⚡

FastAPI Backend

Python 3.11, multi-stage Docker build. Handles all API calls, AI classification, session engine, and AWS orchestration. Port 8000.

📱

MobSF Service

Flask proxy with Docker socket access. Spawns MobSF analysis containers on demand for APK security scanning. Port 5055.

🔷

MariaDB

Primary datastore for normalized events, detections, incidents, evidence and reports, with phpMyAdmin for inspection. Port 3307 on the host.

🔄

Honeypot Sensors

Cowrie, Dionaea and Honeytrap on an isolated edge network. Their only output is the log files the backend collector tails.

🌐

Nginx Frontend

Nginx 1.25 Alpine serving the 30+ page static dashboard. Optimized caching for assets, no-cache for HTML. Port 5500.

Deploy the Full Stack in Minutes

Clone the repo, run ./setup.sh, and all five services start automatically — with OS detection, env setup, and health checks.
