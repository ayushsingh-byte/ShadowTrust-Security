Shadow Trust Backend Architecture

Shadow Trust is a cloud-orchestrated cyber range and honeypot platform for cybersecurity research, malware analysis, and threat intelligence. The backend is designed for modular orchestration, secure VM lifecycle management, and real-time telemetry ingestion, enabling scalable and ephemeral analysis environments.

Core Platform Components

1

Event Ingestion Layer

Honeypot VMs and telemetry agents send structured attack events to the backend. Events are normalized, written to a local SQLite store, and streamed to Supabase for dashboard visualization. High-frequency logging is supported for noisy environments.

2

VM Orchestration Service

Analysis and honeypot VMs are launched from Golden AMIs using AWS EC2 APIs. The backend manages VM lifecycle, tags instances with session IDs, and ensures cost-safe ephemeral compute. No state is stored inside VMs; all persistent data is externalized.

3

Session Engine

Links multiple attack events into sessions, reconstructs timelines, and manages session lifecycle. Enables analysts to trace attacker behavior across VM instances and honeypot logs.

4

Malware Collection Pipeline

When file events are detected, samples are uploaded to S3, hashes are computed, and metadata is stored in Supabase. Samples are linked to attacker sessions for further analysis.

5

Analysis Orchestrator & API Layer

Supports launching analysis VMs, registering jobs, tracking job lifecycle, and auto-terminating instances. Exposes async FastAPI endpoints for VM orchestration, session management, event ingestion, and analysis workflows. Real-time updates are streamed to the dashboard via Supabase or Redis pub/sub.
