MobSF connection Open in new tab

MobSF is used through its API only. It runs in Docker next to the platform; the bridge service looks for it on the first free port between 8000 and 9000.

  1. The bridge checks ports 8000 to 9000 and starts MobSF on the first free one.
  2. Open the MobSF API docs once, copy the key, and paste it into backend/mobsf_service/config.py.
  3. Upload an APK here. It is uploaded, scanned, and the report is loaded into this page.
